# K-AI Brain (Groq) + GitHub executor

Este projeto referencia os segredos abaixo nas funções de servidor:
- GROQ_API_KEY — chave da API do Groq usada pela inteligência do K-AI.

Para configurar: clique no ícone do banco de dados no topo do Bolt, abra "Secrets" e adicione GROQ_API_KEY com sua chave do Groq (https://console.groq.com/keys).
