# K-AI App - Clone Bolt com Supabase

Gemini + GROQ + Pollinations juntos via Supabase Edge Functions

## Backend
- POST /functions/v1/k-ai
- POST /functions/v1/publish

## Secrets (Supabase Dashboard > Edge Functions > Secrets)
GEMINI_API_KEY / GROQ_API_KEY / GH_TOKEN / REPO_TOKEN

## Deploy (se precisar re-deployar)
Via Editor no Supabase ou: supabase functions deploy k-ai / publish
