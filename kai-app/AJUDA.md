# K-AI App - Como usar igual Bolt

1. Na home, escreva o que quer e clique em Build now
2. No chat, peça criar / editar / corrigir / adicionar / melhorar / remover / refazer
3. O chat mostra passos e o preview dentro do chat quando terminar
4. Clique em Preview para ver grande, Código para editar, Publicar para subir pro GitHub

Botoes que funcionam: Novo Projeto, Buscar, Abrir, Duplicar, Excluir, Publicar, Publicar tudo, Copiar, Salvar edição, Novo arquivo, Baixar, Abrir preview em nova aba, Corrigir erro, Melhorar visual, Adicionar, Refazer
